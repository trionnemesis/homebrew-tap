# homebrew-tap

Homebrew tap for [trionnemesis](https://github.com/trionnemesis) projects.

## Install

    brew tap trionnemesis/tap
    brew install --cask aicli-dashboard

## Available casks

| Cask | Description | Source |
|------|-------------|--------|
| `aicli-dashboard` | Desktop widget to monitor AI CLI tool usage and MCP server connections | [macOS_aicli_check](https://github.com/trionnemesis/macOS_aicli_check) |

## Upgrade / Uninstall

    brew upgrade --cask aicli-dashboard
    brew uninstall --cask aicli-dashboard

Issues with the app itself belong in the source repo; tap/packaging issues here.
